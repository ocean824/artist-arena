# Artist Arena Build-Complete V1 Requirements Register

**Authority:** The preserved [`ARTIST-ARENA-V1-Master-Specification.md`](../source/ARTIST-ARENA-V1-Master-Specification.md) provides product canon. [`Owner Directive 0001`](../owner-directives/0001-v1-build-complete.md) supersedes historical statements that classify blockchain, credits, conversions, paid entry, wagering, cash-out, native mobile, streaming, public API, disciplines, or provider integrations as future, later, sandbox-only, disabled, non-goal, or post-V1.

This register contains **exactly 120 atomic V1 requirements**. Every row is `V1-BUILD-REQUIRED`. Assurance and activation are tracked independently so a legal, security, provider, jurisdiction, audit, or rollout gate cannot silently remove construction work.

| Status dimension | Meaning |
|---|---|
| Build obligation | Architecture, executable implementation, integration, tests, admin/operator paths, documentation, and ownership required in V1 |
| Assurance target | Minimum evidence state: Integrated, Verified, Audited, or Production-Qualified |
| Activation class | Broadest intended environment after applicable approvals; a restricted state does not reduce build scope |
| Delivery status | Accepted, In Progress, Implemented, Verified, Superseded, or Removed-by-Owner-Directive; `Deferred` is not a valid V1 status |

Every epic, issue, API/schema/event change, migration, pull request, test plan, release artifact, and evidence package must reference one or more requirement IDs. Child requirements may add specificity but may not weaken these obligations without a later owner directive.
