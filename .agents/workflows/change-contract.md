# Workflow: Change Contract

Identify every producer and consumer; draft an ADR/RFC if required; version schemas/APIs/events; generate/update clients; add compatibility and migration tests; roll out additively; monitor; then deprecate.

Every step must reference requirements, actor authority, affected trust zones, commands/events/state changes, tests, evidence, and rollback. Never put secrets or sensitive user data into prompts, issues, commits, logs, or project memory.
