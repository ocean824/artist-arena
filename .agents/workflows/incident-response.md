# Workflow: Incident Response

Detect, classify, contain, preserve evidence, protect users and funds, communicate through authorized channels, recover, reconcile, remediate, review, and track corrective actions without rewriting immutable history.

Every step must reference requirements, actor authority, affected trust zones, commands/events/state changes, tests, evidence, and rollback. Never put secrets or sensitive user data into prompts, issues, commits, logs, or project memory.
