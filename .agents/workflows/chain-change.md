# Workflow: Chain Change

Define deterministic state and invariants; update simulator, module, wallet/indexer contracts, migration/upgrade, fault tests, backup/restore, security analysis, and testnet evidence before any production proposal.

Every step must reference requirements, actor authority, affected trust zones, commands/events/state changes, tests, evidence, and rollback. Never put secrets or sensitive user data into prompts, issues, commits, logs, or project memory.
