# Workflow: Production Activation

Verify build and assurance status; compile provider/legal/operator/jurisdiction/security/operations evidence; require explicit human approval; activate narrowly; monitor; retain an emergency disable and rollback/recovery path.

Every step must reference requirements, actor authority, affected trust zones, commands/events/state changes, tests, evidence, and rollback. Never put secrets or sensitive user data into prompts, issues, commits, logs, or project memory.
